# dental — инструкции для Claude

Учебный проект для удовольствия: Telegram-бот и Mini App записи к знакомому стоматологу
(Бишкек). Владелец — Java-разработчик, учится на нём; код пишет Claude, объясняя решения —
зачем, почему так и какие были альтернативы. Общение на русском.

Дизайн и решения ревью — в сессии /office-hours от 2026-10-22 (копия будет в `docs/design.md`).

## Команды

- `./mvnw verify` — сборка и тесты (нужен Docker). CI (`.github/workflows/ci.yml`) делает
  то же на каждый push и PR.
- `./mvnw spring-boot:run` — профиль `local`, база из `compose.yaml` на `localhost:5433`.

## Правила

- **Только тестовые пациенты** до шага 8 (реестр ГАЗПД, согласие, глава 11 Цифрового кодекса КР).
  Настоящие данные пациентов никогда не попадают в репозиторий (он публичный).
- Персональные данные (имя, телефон) не писать в логи, URL и в утреннюю сводку бота.
- Секреты (токен бота, пароли) — только переменные окружения или `.env` (в `.gitignore`).
- Схема БД — только новой миграцией Flyway; применённые миграции не редактировать.
- Двойную запись запрещает база (`appointment_no_overlap`); нарушение 23P01 → ответ 409.
  Сохранять через `saveAndFlush`, чтобы ошибка случилась внутри запроса, а не при коммите.
- Время в базе — UTC (`timestamptz`), показываем по Asia/Bishkek.
- Слои: Controller → Service → Repository на каждую сущность.
- Тесты с базой — Testcontainers и настоящий Postgres, не H2.
- Прод и сервер менять — только с явного согласия владельца.
